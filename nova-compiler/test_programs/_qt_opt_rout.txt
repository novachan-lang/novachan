NOVA Programming Language v0.1.0
Usage: nova <command> [options] [file.nova]

Project commands:
  new <name>            Create a new project skeleton
  init                  Create nova.toml in current directory
  build [file]          Build project (or specific file) to executable
  run [file]            Build and run project (or specific file)
  test                  Run all *_test.nova files in tests/ and ./
  clean                 Remove .ll, .exe build artifacts
  fmt <file.nova>       Format source (whitespace normalization)
  lint <file.nova>      Static checks (tabs, line length, TODOs)
  check <file.nova>     Parse + type-check only (no codegen) — fast
  repl                  Start interactive shell (compiles + runs repl.nova)
  debug <file.nova>     Build with debug info and launch lldb
  bench <file.nova>     Build then time N runs (min/mean/max)
  cov <file.nova>       Build with coverage and run; per-line report on exit

Single-file commands:
  compile <file.nova>   Compile to LLVM IR only
  emit <file.nova>      Print generated LLVM IR to stdout (inspect codegen)

Package commands:
  get <package>[@ver]   Add a dependency to nova.toml
  install               Download all dependencies from nova.toml

Tools:
  version               Show version
  self-test             Run compiler self-test
  lsp                   Start LSP server (for IDE integration)

Options:
  -O0                   Disable optimizations
  -o <output>           Output file path
  --target <target>     Cross-compile target:
    linux, linux-arm64, macos, macos-arm64, windows, wasm
  --old                 Use legacy non-IR compiler
