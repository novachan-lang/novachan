test(async): monitor-based supervised gen_server -- OTP supervisor<->gen_server loop

A supervisor spawns a worker gen_server, MONITORS it (monitor(pid) returns a channel that fires
with the worker's exit status when it dies), sends a request, and RESTARTS the worker on failure
until it succeeds -- recovering after exactly 2 restarts with the success payload. Composes monitor
+ spawn + mailbox + selective receive into OTP's supervision pillar, with NO framework -- just the
language. New capability vs supervisor_test (which uses channel rendezvous): this detects the
worker's actual DEATH via the monitor primitive and restarts.

Scope: fault signaling is NOVA-way explicit (the worker reports failure then exits; the supervisor
observes the death via the monitor channel and restarts). True OS-crash isolation across green
tasks remains the deeper Track-8 ownership work.

Pure NOVA -- no compiler/runtime change. Registered in _run_final_regression.ps1; passes NORMAL +
FULLRC + ASAN-clean.
