The NOVA Tutorial

A guided walk from zero to a deployed full-stack application in NOVA. Every snippet compiles with the current nova binary. If something doesn't work, that's a bug — file it.

Every code block on this page is real, compile-verified NOVA. Nothing is pseudocode or aspirational syntax.

1. Install

NOVA compiles through LLVM. You need two things:

  • clang — install via the LLVM project or your package manager
  • The nova binary — currently shipped as gen3_test.exe in nova-compiler/test_programs/

For day-to-day use, alias it:

bash
# Linux/macOS
alias nova='/path/to/gen3_test.exe'

# Windows PowerShell
Set-Alias nova C:\path\to\gen3_test.exe

2. Hello, world

Create hello.nova:

nova
fn main()
    print("Hello, world!")

Compile and run:

bash
nova run hello.nova

What just happened:

  1. nova parsed hello.nova and emitted LLVM IR (hello.ll)
  2. It invoked clang to link with the NOVA C runtime
  3. The resulting native executable ran and printed the message

nova run is the all-in-one shortcut. nova build hello.nova stops at the executable; nova compile hello.nova stops at the .ll.

3. Values and types

NOVA has six primitive value families and infers their types — you almost never write annotations:

nova
fn main()
    let n      = 42                         // int
    let pi     = 3.14                       // float
    let name   = "NOVA"                     // string
    let active = true                        // bool
    let items  = [1, 2, 3]                 // list
    let config = {"host": "localhost"}     // dict
    print(n)
    print(name)

You can annotate at function boundaries — useful for documentation and better error messages:

nova
fn rectangle_area(w: int, h: int) -> int
    w * h

4. Control flow

NOVA uses indentation for blocks. No braces.

If

nova
fn classify(n: int) -> string
    if n > 0
        "positive"
    else if n == 0
        "zero"
    else
        "negative"

if is an expression: the last expression in each branch is the value.

While

nova
fn sum_to(n: int) -> int
    let total = 0
    let i = 1
    while i <= n
        total = total + i
        i = i + 1
    total

For

nova
fn main()
    for x in [1, 2, 3, 4, 5]
        print(x)

    for i in range(0, 10)
        print(i)

range(a, b) produces [a, a+1, …, b-1]. range(a, b, step) adds a stride.

5. Functions

nova
fn add(a: int, b: int) -> int
    a + b

fn greet(name)
    print("Hello, " + name + "!")

fn factorial(n)
    if n <= 1
        return 1
    n * factorial(n - 1)

Three things to notice: the last expression of a block is its return value; return is available for early exit; parameter types are optional.

Default arguments

nova
fn greet(name, prefix = "Hello")
    print(prefix + ", " + name + "!")

fn main()
    greet("world")            // Hello, world!
    greet("world", "Hi")     // Hi, world!

6. Lists, dicts, strings

Lists

nova
fn main()
    let xs = [1, 2, 3]
    push(xs, 4)
    print(len(xs))     // 4
    print(xs[0])      // 1
    print(xs[2:4])    // [3, 4]

    for x in xs
        print(x * 2)

Dicts

nova
fn main()
    let user = {"name": "alice", "age": 30}
    user["email"] = "alice@example.com"
    print(user["name"])
    for k in keys(user)
        print(k)

Strings

nova
fn main()
    let s = "hello world"
    print(len(s))               // 11
    print(slice(s, 0, 5))       // "hello"
    print(split(s, " "))         // ["hello", "world"]
    print(replace(s, "world", "NOVA"))

7. Structs and enums

Structs

nova
type Point
    x: int
    y: int

fn dist_sq(p: Point) -> int
    p.x * p.x + p.y * p.y

fn main()
    let p = Point(3, 4)
    print(dist_sq(p))   // 25

Enums (sum types)

nova
enum Shape
    Circle(radius: float)
    Rect(width: float, height: float)

fn area(s: Shape) -> float
    match s
        Circle(r)    => 3.14159 * r * r
        Rect(w, h)   => w * h

fn main()
    print(area(Circle(5.0)))
    print(area(Rect(3.0, 4.0)))

8. Pattern matching

match handles ints, strings, bools, structs, enums, and wildcards. Match is exhaustive — the compiler warns if you miss a case for a closed enum.

nova
fn classify(x: int) -> string
    match x
        0             => "zero"
        1             => "one"
        n if n < 0   => "negative"
        n if n > 100 => "big"
        _             => "small positive"

9. Closures and higher-order functions

nova
fn apply_twice(f, x)
    f(f(x))

fn main()
    let scale = 3
    let triple = x => x * scale   // captures scale from outer scope
    print(triple(7))               // 21

    print(apply_twice(x => x + 1, 5))  // 7

10. Error handling

NOVA has two mechanisms that interoperate.

Result with ok / err and ?

nova
fn safe_divide(a: int, b: int) -> Result
    if b == 0
        return err("div by zero")
    ok(a / b)

fn compute(x: int, y: int) -> Result
    let q = safe_divide(x, y)?   // ? propagates err to caller
    ok(q * 2)

fn main()
    match compute(10, 2)
        ok(v)  => print(v)
        err(m) => print("failed: " + m)

Assertions

nova
assert(x > 0, "x must be positive")
assert_eq(actual, expected)
assert_near(measured, expected, 0.001)

11. Processes and channels

NOVA's concurrency primitives: spawn a process, communicate over channels. Processes never share memory — a value crossing a channel is moved to the receiver.

nova
fn worker(ch)
    let i = 0
    while i < 5
        send(ch, i)
        i = i + 1

fn main()
    let ch = channel()
    spawn worker(ch)
    let total = 0
    let i = 0
    while i < 5
        total = total + receive(ch)
        i = i + 1
    print(total)   // 10

Select — first channel wins

nova
fn main()
    let a = channel()
    let b = channel()
    spawn fn() send(a, 1)
    spawn fn() send(b, 2)
    let v = select(a, b)   // whichever arrives first
    print(v)

12. Modules

A .nova file IS a module. The file name is the module name. Names starting with _ are file-private.

nova
// mathx.nova
fn double(x: int) -> int
    x * 2

fn _private_helper(x)   // only visible inside mathx.nova
    x + 1
nova
// main.nova
import mathx

fn main()
    print(mathx.double(21))   // 42

Selective and aliased imports:

nova
import mathx { double }   // brings double into scope unqualified
import mathx as m         // use m.double

13. FFI: calling C

NOVA can call any C function via extern fn:

nova
@link("c")
extern fn strlen(s: string) -> int

fn main()
    print(unsafe strlen("hello world"))   // 11

@repr(C) structs

nova
@repr(C)
type Vec3
    x: float
    y: float
    z: float

@link("mymath")
extern fn vec3_length(v: Vec3) -> float

14. Building a web service

A complete TODO API in ~20 lines using NOVA's forge framework:

nova
import forge

let _todos = []

fn route(method: string, path: string, body: string) -> string
    if method == "GET" and path == "/todos"
        return forge.json(200, str(_todos))
    if method == "POST" and path == "/todos"
        push(_todos, body)
        return forge.text(201, "created")
    forge.text(404, "not found")

fn main()
    forge.serve(8080, route)
bash
nova run todo_server.nova
curl http://localhost:8080/todos
curl -X POST -d "milk" http://localhost:8080/todos

15. Adding AI inference

NOVA's cortex framework provides classification using built-in tensor ops. No Python. No IPC. The whole binary is ~1 MB.

nova
import cortex
import forge

fn route(method: string, path: string, body: string) -> string
    if method == "POST" and path == "/classify"
        let w = tensor_from_list([1.0, 2.0, 0.0, 0.0, 1.0, 1.0], [2, 3])
        let x = tensor_from_list([1.0, 2.0, 3.0], [1, 3])
        let result = cortex.classify(w, x)
        return forge.json(200, '{"class":' + str(result[0]) + '}')
    forge.text(404, "?")

fn main()
    forge.serve(8080, route)

Live deployment: This exact pattern was deployed on Railway over HTTPS and served real predictions — see the deploy section below.

Normative reference

The NOVA Language Specification

The authoritative reference for NOVA as implemented by gen3_test.exe. For a guided introduction, read the Tutorial first. This document assumes you know what NOVA looks like.

1. Lexical structure

Encoding and indentation

Source files are UTF-8. NOVA is indentation-sensitive — blocks are introduced by indenting one level deeper than the opening line. Tabs and spaces are not interchangeable within the same file.

Comments

nova
// Single-line comment, runs to end of line.
// There is no block-comment syntax.

Identifiers

Letters, digits, and underscores; must start with a letter or _. Identifiers starting with _ at the top level are file-private.

Reserved keywords

2. Types

Primitives

  • int — 64-bit signed, two's-complement, wraps on overflow (no UB)
  • float — 64-bit IEEE 754 double
  • bool — true or false
  • string — immutable UTF-8 byte sequence
  • unit — the type of a no-value expression

Containers

  • list<T> — dynamic array, heap-allocated, reference-counted
  • dict<K, V> — open-addressing hash map, heap-allocated, reference-counted

User-defined (structs)

nova
type Name
    field1: T1
    field2: T2

Enums (sum types)

nova
enum Name
    Variant1
    Variant2(field: T)
    Variant3(a: T, b: U)

Generics

Generics are erased at compile time — no monomorphization cost at runtime. Representations are uniform i64 slots.

nova
fn map<T, U>(xs: list<T>, f: T -> U) -> list<U>

3. Values, processes, channels

The entire NOVA computational universe is three primitives:

  • Values — every datum. All values have a single owner at any time.
  • Processes — every unit of execution. Created by spawn. Processes do not share heap. Single-process programs compile the spawn machinery away to zero overhead.
  • Channels — every cross-process communication. A send may move the value. Under NOVA_TRACK8=1 this is checked statically at compile time.

5. Statements

let name = expr declares a binding; the compiler infers the type. name = expr mutates an existing binding. Compound assignment: += -= *= /= %=.

return returns from the enclosing function; the last expression in a block is an implicit return. break exits the nearest loop; continue jumps to the next iteration. import is top-level only.

6. Functions

nova
fn name(params) -> return_type
    body

Parameters and return type are optional; both are inferred. Functions are first-class values.

Methods

nova
fn TypeName.method(self, args) -> R
    body

Traits

nova
trait Show
    fn show(self) -> string

impl Show for int
    fn show(self) -> string
        str(self)

fn print_all<T: Show>(xs: list<T>)
    for x in xs
        print(x.show())

7. Type system

NOVA's type system is a Hindley-Milner core extended with subtyping at structural seams. Inference is sound but not complete — the compiler will reject some safe programs, but never accept an unsafe one. In practice you need annotations in two places:

  1. Public function signatures (documentation + better errors)
  2. Disambiguating overloads (rare)

8. Modules

Every .nova file is a module. import math looks for math.nova in: the importing file's directory → ./nova_packages/math/math.nova → stdlib search path. Top-level names are public unless they start with _.

FormEffect
import mathBinds math.* qualified
import math as mBinds under alias m
import math { sin, cos }Brings into scope unqualified

9. Memory model

NOVA uses process-isolated, reference-counted, escape-analyzed memory.

  • Lists, dicts, strings (non-constant), structs, closures, channels — heap-allocated with refcount
  • Integers, floats, bools, constant strings — not heap-allocated

Track 8 escape analysis determines which allocations are process-local. Local containers use _no_rc variants of push/set — eliminating ~20% of RC traffic on container-heavy workloads. For programs that never spawn, NOVA_AUTO_ARENA=1 turns the entire RC machinery into a no-op.

Move semantics on channels: send(ch, x) may move x to the channel. Under NOVA_TRACK8=1, any use of x after the send is a compile error (E1003).

11. Compilation pipeline

.nova → lexer → parser → type inferrer → IR builder → optimizer → LLVM emitter → clang → .exe
  1. Lexer — tokenizes UTF-8 source
  2. Parser — Pratt-style precedence parser builds an AST
  3. Type inferrer — Hindley-Milner + constraint solving + trait conformance
  4. IR builder — lowers AST to basic-block IR with named registers
  5. Optimizer — TCO, dead-block/instruction elimination, constant folding, escape analysis
  6. LLVM emitter — writes textual LLVM IR with TBAA metadata and DWARF debug info
  7. clang — links .ll with nova_runtime.c to produce native executable

Deterministic: the same source compiles to the same .ll byte-for-byte, regardless of host filesystem ordering. Self-hosting: nova_compiler.nova (~12k lines of NOVA) compiles itself.
