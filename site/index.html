The Problem

Computing is fragmented. NOVA unifies it.

Today you need C for the kernel, Rust for safety, Python for AI, JavaScript for the browser, Go for the server — five languages, five toolchains, five mental models, glued together at every boundary. Every seam is a place for bugs, friction, and lost productivity.

NOVA collapses them into one core model expressive enough to represent every domain — so the developer never has to leave the language.

The Model

Everything is three things.

NOVA's entire computational universe is built from three primitives. Master these, and you can express any program — for any target.

Values

All data, across all domains. The compiler infers the type, allocation strategy, and capabilities — no annotations.

  • Integers, structs, lists, dicts
  • Tensors, byte buffers, JSON
  • Even processes & channels are values

Processes

All units of execution. A spawn creates one; processes never share heap. Single-process code compiles the machinery away to zero overhead.

  • Threads, actors, GPU kernels
  • Edge functions, distributed nodes
  • Isolation is memory safety

Channels

All communication. Typed, so the compiler verifies both ends agree. A send transfers ownership at the boundary.

  • Function calls, network streams
  • GPU transfers, events
  • Statically-checked moves
See It

Simple to write. Fast to run.

Every snippet below is real NOVA — compiled, linked, and run by the bundled compiler. Nothing is mocked.

// The absolute simplest program — zero ceremony.
fn main()
    print("Hello, NOVA!")
// Recursion that reads like English. No type annotations —
// the compiler infers the parameter and return types.
fn fib(n)
    if n < 2
        return n
    return fib(n - 1) + fib(n - 2)

fn main()
    print(fib(10))   // 55
// Real data work: filter-and-sum, then a word-frequency dict.
fn main()
    let prices = [12, 7, 30, 5, 22]
    let total = 0
    for p in prices
        if p > 10
            total = total + p

    let counts = {}
    for word in ["go", "go", "nova", "go"]
        if contains(counts, word)
            counts[word] = counts[word] + 1
        else
            counts[word] = 1
    print(counts["go"])   // 3
// Processes + Channels: two workers each sum half the
// range and send their partial; main combines them.
ch1 = channel()
ch2 = channel()

spawn fn()
    sum = 0
    i = 1
    while i <= 50
        sum = sum + i
        i = i + 1
    send(ch1, sum)

spawn fn()
    sum = 0
    i = 51
    while i <= 100
        sum = sum + i
        i = i + 1
    send(ch2, sum)

total = receive(ch1) + receive(ch2)
print(total)   // 5050
// Numeric code: a vec3 as a float list, dot product,
// and Euclidean length via the sqrt builtin.
fn dot(a, b)
    a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

fn length(v)
    sqrt(dot(v, v))

fn main()
    let v = [3.0, 4.0, 0.0]
    print(length(v))   // 5.0
// Not one type annotation. The compiler infers the int
// list, the float list (from n * 2.5), and the string.
fn main()
    let nums = [1, 2, 3, 4, 5]
    let scaled = []
    for n in nums
        push(scaled, n * 2.5)
    print("items: " + str(len(scaled)))
    print(scaled[4])   // 12.5
Why NOVA

Built to beat every language at its own game.

⚙︎

The Genius Compiler

You write annotation-free code. A Hindley-Milner core infers every type; escape analysis infers ownership and memory strategy. All the hard work lives in the compiler.

⚡

C-Level Speed

An LLVM backend with zero-cost erasure. The self-hosted compiler runs within ~2% of equivalent C on its core benchmarks — sieve, primes, matmul.

🛡

Safe by Default

Process isolation plus reference counting with RC elision — memory-safe without GC pauses. Integer arithmetic wraps: defined behavior, never undefined.

⇶

Fearless Concurrency

spawn is as easy as Go's go. Typed channels verify both ends; ownership transfers on send. No data races by construction.

◎

Runs Anywhere

Native on Windows and Linux today. WebAssembly (compute) and CPU-backed GPU compute are wired. Same source, deterministic byte-identical output.

🧰

One Toolchain

Build, run, test, format, and package — all built in. nova build, nova test, nova fmt, a semver package manager, and an LSP for your editor.
